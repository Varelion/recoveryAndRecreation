# 🛒 Purse Template

One purse per character, titled with the character's name. Open it with the header, then reply once per purchase, sale or scry. Staff confirm each line. Catalog: {#market-guide}.

## Purse header
```
**CHARACTER:** name · profile link
**BALANCE:** 500 Marks
**OWNED:** item (price), one per line
```

## Purchase or sale
```
**BUY / SELL:** item
**PRICE:** Marks (sales return half)
**BALANCE AFTER:**
```

## Scry
```
**SCRY:** week of YYYY-MM-DD, from region
```
