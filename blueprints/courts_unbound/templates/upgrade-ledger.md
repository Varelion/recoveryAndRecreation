# 📈 Upgrade Ledger

One ledger per approved character, titled with the character's name. Open it with the header below, then reply once per change. A {@Lorekeeper} confirms each entry; then update your profile. Rules: {#progression}.

## Ledger header
```
**CHARACTER:** name · profile link
**RANK / TIER:**
**ABILITIES:**
Ability [Tier] · progress to next tier: 0 / N threads
```

## RANK UP
```
**RANK UP**
Ability:
From → To: tier → tier
Threads: links, with boosts declared, and total credit
```

## I HAVE LEARNED
```
**I HAVE LEARNED**
New ability: name [Beginner]
Cost: 3 × abilities held = N threads
Threads: links, including the on-screen one where it happened
Teacher: who, for house or secret arts
```

## PROFILE ADJUSTMENT
```
**PROFILE ADJUSTMENT**
Section: appearance / personality / history / other
Change: what changes, and why
Threads: links, if any
```
