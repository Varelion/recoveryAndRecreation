# 📜 Mission Guidelines

Full rules: {#missions-guide}.
- Any Courtier or higher may run Errand and Task missions. {@Storyteller}s run Venture, Peril and Nightmare.
- Game masters voice the world and NPCs, never another player's character.
- Rate difficulty honestly. Staff downgrade inflated missions.
- Send the template for review: Storytellers in the story workshop, everyone else in a **Mission Review** ticket. Staff post approved missions here.
- **Players:** reply inside a mission to join it.

## Copy below
```
**NAME:**
**TIER:** Errand / Task / Venture / Peril / Nightmare
**DE:** yes / no
**SLOTS:** how many players, counting yourself if you play
**GAME MASTER:** @you
**WHERE:** location forum or bubble
**BRIEF:** what the mission is, in a paragraph or two
**REWARD:** anything beyond Renown and Marks
**ROSTER:**
```
