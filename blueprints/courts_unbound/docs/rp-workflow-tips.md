# Discord Roleplay QoL Tips – Faster RP Workflow

**CTRL + K** (Quick Switcher)
Opens a search box you can type into right away. Type a thread, channel or DM name, hit Enter, start writing.
-# On Mac, use Command instead of CTRL.

**CTRL + K → Enter**
Takes you straight back to the previous channel. Press it over and over to bounce between two scenes, or between a scene and your character sheet.

**ALT + Left Arrow / ALT + Right Arrow**
Back and forward through the threads, channels and DMs you visited recently.

**ALT + Click** on a message
Marks it unread. Read a post but can't reply yet? ALT + Click it and go. It'll still be waiting for you.

**CTRL + I**
Opens your inbox: mentions, tags, unread threads.

**WIN + .** (Windows emoji panel)
Emoji, kaomoji (◕‿◕) and symbols like — é ★ ♪, usable in any text box. Handy for dialogue, names and formatting.

**WIN + V** (Windows clipboard history)
Brings back everything you copied recently. Pin text you use a lot: character intros, post templates, links. Turn it on the first time you press it.

**CTRL + /**
Lists every Discord hotkey.
